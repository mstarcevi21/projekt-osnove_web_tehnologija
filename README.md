# Pikado Portal — Web Aplikacija

Interaktivna web aplikacija za upravljanje pikado turnirima, igračima i opremom. Projekt je nastao u sklopu kolegija *Osnove web tehnologija*, a refaktoriran je i prilagođen za samostalno pokretanje i produkcijski deployment.

🔗 **Link na web stranicu:** (https://projekt-osnove-web-tehnologija.onrender.com)

---

## Korištene tehnologije

- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3 (fleksibilni i responzivni dizajn), Vanilla JavaScript (ES6)
- **Pohrana podataka:** CSV datotečni sustav (`zapisi.csv`)
- **Deployment:** Render / GitHub

---

## Upute za lokalno pokretanje

Za pokretanje ovog projekta na svom računalu potrebno je imati instaliran [Node.js](https://nodejs.org/).
