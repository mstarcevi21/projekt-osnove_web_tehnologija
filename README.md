# Pikado Portal — Web Aplikacija

Interaktivna web aplikacija za upravljanje pikado turnirima, igračima i opremom. Projekt je nastao u sklopu kolegija *Osnove web tehnologija*, a refaktoriran je i prilagođen za samostalno pokretanje i produkcijski deployment.

🔗 **Link na web stranicu:** (https://projekt-osnove-web-tehnologija.onrender.com)

---

## Korištene tehnologije

- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, CSS3 (fleksibilni i responzivni dizajn), Vanilla JavaScript (ES6)
- **Pohrana podataka:** CSV datotečni sustav (`zapisi.csv`)
- **Deployment:** Render / GitHub

---

## Upute za lokalno pokretanje

Za pokretanje projekta na lokalnom računalu potrebno je imati instaliran [Node.js](https://nodejs.org/) 

### 1. Kloniranje repozitorija
U terminalu upišite:
git clone [https://github.com/VASE_KORISNICKO_IME/pikado-portal.git](https://github.com/VASE_KORISNICKO_IME/pikado-portal.git)
cd pikado-portal

### 2. Instalacija zavisnosti
U korijenskom direktoriju projekta pokrenite:
npm install

### 3. Pokretanje poslužitelja
Aplikaciju pokrećete naredbom:

npm start
Nakon pokretanja, aplikacija je dostupna u vašem web pregledniku na adresi:

http://localhost:3000
