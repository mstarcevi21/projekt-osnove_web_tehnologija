Sadržajni minimum

Popis svih elemenata sadržajnog minimuma zadaće s poveznicama na stranice gdje su realizirani.

  • 1. Početna stranica — index.html
    Hero sekcija, kartice, slike, navigacija
  • 2. Tablica (5×7, thead/tbody/tfoot/caption) — igraci.html
    PDC ljestvica poretka, 10 igrača, scope atributi
  • 3. Kompleksniji vizualni CSS element (lightbox) — galerija.html
    CSS-only lightbox s radio input (:checked) i ~ selektorom
  • 4. Obrazac s JS validacijom (13 vrsta elemenata) — obrValidacija
    text, email, tel, url, number, range, date, select, radio, checkbox, color, textarea, search — validacija u mstarcevi21_obrazac.js
  • 5. Ostale stranice — turniri.html, pravila.html, oprema.html
    Turniri (kartice), Pravila (dvostupčani layout, tablica), Oprema (dl/dt/dd)
  • 6. Minimalno 3 slike — index.html
    3 slike u sekciji "Slike iz sporta", + slike u galeriji
  • 7. Funkcionalna navigacija bez JS — sve stranice
    CSS stiliziran nav s :hover i .aktivna klasom; JS dinamički dodaje gumb i označava aktivnu stavku
  • 8. Responzivnost (desktop/tablet/mobitel) — responzivnost.css
    @media breakpointi na 900px i 600px
  • 9. NodeJS poslužitelj — server.cjs
    Express poslužitelj koji servira sve stranice, statičke datoteke i API endpoint /api/zapisi
  • 10. Pregled zapisa iz CSV-a — pregled
    Dinamički prikaz zapisa iz zapisi.csv s pretraživanjem i filtriranjem po kategoriji
  • 11. REST API — /api/zapisi
    GET /api/zapisi, GET /api/zapisi/:id, POST, PUT, DELETE — zapisi.cjs modul
  • 12. Dokumentacija (samo Bootstrap) — dokumentacija.html
    Ova stranica — Bootstrap 5, bez mstarcevi21.css

Tehnička rješenja

CSS-only lightbox

Galerija koristi CSS-only lightbox bez JavaScripta. Tehnika se oslanja na skrivene radio input elemente i CSS selektor tilde (~) koji primjenjuje stil na elemente koji slijede iza provjerenog inputa. 

#slika-1:checked ~ .lightbox-1 {
    display: flex;
}
CSS varijable i struktura

Sve boje i razmaci definirani su kao CSS varijable u :root bloku. To omogućuje lako mijenjanje cijelog dizajna na jednom mjestu. 

:root {
  --boja-primarna: #c0392b;
  --razmak-srednji: 1rem;
}
JS validacija obrasca

JavaScript u mstarcevi21_obrazac.js provjerava 7 pravila: obavezna polja, format e-maila i telefona, odnos datuma i godina igranja te opširnost poruke kod prijave greške. 

obrazac.addEventListener("submit",
  function (dogadaj) {
    if (!provjeriObrazac(obrazac)) {
      dogadaj.preventDefault();
    }
  }
);
